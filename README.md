# Simple AI Chatbot
A simple command-line AI assistant built with LangChain, Hugging Face, and Llama 3.1.

## Features

* Interactive AI chat
* Llama 3.1 8B Instruct model
* LangChain prompt and output parser
* Simple command-line interface
* Exit with exit, quit, or bye

## Tech Stack

* Python
* LangChain
* Hugging Face
* Llama 3.1
* python-dotenv

## Usage

Run the project and type your question in the terminal.

Type exit, quit, or bye to end the chat.
